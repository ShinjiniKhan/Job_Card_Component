# Job Listing Cards Component

A responsive Job Listing UI built using **React** and **Vite**. This component displays job opportunities across top tech companies with key details such as role title, company name, employment type, experience level, location, hourly rate, and an apply button.

##  Features

* **Dynamic Job Cards**: Renders job listings with company branding and tag chips (e.g., Full Time, Senior Level).
* **Clean UI Layout**: Grid layout designed for easy browsing across desktop and mobile screens.
* **Interactive Elements**: Save listing bookmark actions and direct action buttons (Apply Now).

##  Tech Stack

* **React** (JSX)
* **CSS3**
* **Vite**
